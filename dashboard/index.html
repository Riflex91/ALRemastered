Developer manual controls

Movement test controls

Slice 3.2 only sends a fixed 32-unit same-map step after Adventure Land geometry validation. XMove uses the direct path only; if pathfinding would be required, the test is rejected instead of starting hidden navigation.

Attack test controls

Slice 3.3 performs exactly one normal attack against the explicitly selected live monster. The target must still be visible and in range, cooldown must be clear, and the Adventure Land server must confirm the result. No automatic targeting or repeated attack loop is used.

Skill test controls

Slice 3.4 exposes only simple non-hostile skills validated from the loaded Adventure Land G.skills data. Special-argument, movement, item-consuming, multi-target, hostile, passive, and arbitrary skill payloads are excluded. Each click sends at most one skill and waits for the Adventure Land server result.

Loot & consumable test controls

Slice 3.5 exposes only currently visible loot chests and exact inventory slots whose current G.items data grants one positive HP or MP resource. Each click performs exactly one validated Action Gateway request and waits for Adventure Land server confirmation. No auto-loot, auto-potion loop, free-form item ID, socket payload, or farming loop is exposed.
